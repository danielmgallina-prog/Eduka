# Mascote

- `kadu.svg` — Kadu neutro, cabeça flutuante com a peça laranja. Cores fixas no arquivo.
- `kadu-comemorando.svg` — Olhos fechados de alegria e brilhos. Acerto, nível novo, missão concluída.
- `kadu-dica.svg` — Orelha tombada, olhando para a peça. Feedback depois de um erro.
- `kadu-avatar.svg` — Kadu em círculo violeta. Notificações e cantos de tela, mínimo 32px.
